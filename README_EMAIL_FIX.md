# HireTrust Email Setup

The candidate's email address is **not** the SMTP configuration. HireTrust needs a sender mailbox.

For Gmail:
- SMTP Host: smtp.gmail.com
- SMTP Port: 465
- Secure TLS: checked
- SMTP Username: your Gmail address
- SMTP Password: a Google App Password (16 characters), not your normal Gmail password
- From Email: the same Gmail address

Then click **Save Email Settings**, **Check Configuration**, and **Send Test Email**.

The schedule page will still save an interview even when email is unavailable, but it will clearly report whether candidate/interviewer notifications were sent.
